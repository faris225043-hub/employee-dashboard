
# EmployeeHub - Employee Dashboard

A React-based Employee Dashboard built using React, Vite, and React Router.

## Features

- Dashboard displaying employee ID, name, and email.
- Employee data fetched from JSONPlaceholder API.
- Navigation between Home and Employee Form.
- Employee form with Name, Designation, Location, and Salary.
- Browser localStorage for saving newly added employees.
- Responsive CSS styling.

## Technologies Used

- React
- Vite
- React Router DOM
- CSS
- JavaScript
- JSONPlaceholder API

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.
